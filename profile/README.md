# Curse

Curse is a Minecraft: Java Edition 26.3 client and server engine written in Rust.

- **Download:** https://curse-rusts.github.io
- **Launcher, game builds and server archives:** https://github.com/curse-rusts/downloads
- **Documentation:** https://curse-rusts.github.io/docs.html

The source is private. This organisation publishes builds, not code.

Curse is not affiliated with Mojang Studios or Microsoft.
